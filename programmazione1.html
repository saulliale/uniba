Introduzione al Linguaggio C

1. Architettura e Struttura di un Programma in C

Un programma in C è una sequenza ordinata di righe di codice che si suddividono in tre categorie concettuali:

  • Dichiarazioni: specificano le variabili, le funzioni e i tipi di dati.
  • Istruzioni (Statement): rappresentano le azioni eseguibili (devono terminare con ;).
  • Commenti: note esplicative per il programmatore.
/* Fig. 2.1: fig02_01.c A first program in C */ #include <stdio.h> /* function main begins program execution */ int main( void ) { printf( "Welcome to C!\n" ); return 0; /* indicate that program ended successfully */ } /* end function main */

Punti chiave:

  • #include <stdio.h>: Direttiva del preprocessore che carica la libreria di Input/Output.
  • int main(void): Il punto d'inizio obbligatorio dell'esecuzione. Restituisce un intero (int) e non prende parametri (void).
  • Le parentesi graffe { } delimitano i blocchi di codice.
  • Il Linker collega le funzioni di libreria (come printf) al programma. Errori di battitura qui causeranno un errore del linker.

2. Formattazione e Sequenze di Escape

Il carattere backslash \ è il carattere di escape. Indica che il carattere successivo esegue un'operazione speciale.

Sequenza Nome Descrizione
\n Newline (A capo) Posiziona il cursore all'inizio della riga successiva.
\t Horizontal tab Sposta il cursore al successivo punto di tabulazione.
\a Alert Produce un segnale acustico di sistema (campanella).
\\ Backslash Inserisce un carattere di barra rovesciata nella stringa.
\" Double quote Inserisce un doppio apice all'interno della stringa.

4. Concetti di Memoria: Stack ed Heap

Ogni variabile rappresenta una locazione in RAM caratterizzata da: Nome, Tipo e Valore. L'assegnamento è un'operazione distruttiva (sovrascrive il vecchio valore).

5. Input dei Dati (scanf) e Tipi Fondamentali

La funzione scanf legge input da tastiera. Richiede la specifica di formato (es. %d) e l'operatore di indirizzo & per sapere in quale locazione RAM salvare il dato.

int a; /* Tipo Intero: %d */ char c; /* Tipo Carattere: %c */ float f; /* Tipo Reale: %f */ scanf("%d", &a);
Pulizia del Buffer (stdin): Residui (come il tasto Invio \n) possono creare bug in acquisizioni multiple. Per pulire il buffer si usa:

fflush(stdin); oppure
while (getchar() != '\n');

6. Operatori Aritmetici e Precedenza

In C, l'operatore = assegna il valore calcolato a destra alla variabile di sinistra.

Operazione Operatore C Precedenza
Parentesi ( ) Massima (da interno verso esterno)
Moltiplicazione / Divisione / Modulo *   /   % Livello 3 (da sx a dx)
Addizione / Sottrazione +   - Livello 4 (da sx a dx)
Assegnamento = Bassa (da dx a sx)

Nota sul modulo (%): Restituisce il resto della divisione intera (es. 7 % 5 restituisce 2).

7. Logica Decisionale: Costrutti IF, ELSE e Flowchart

Le condizioni in C si basano sulla Convenzione della Verità: il valore 0 rappresenta il FALSO, qualsiasi altro valore rappresenta il VERO.

if (numero > 0) { printf("Positivo\n"); } else if (numero < 0) { printf("Negativo\n"); } else { printf("Zero\n"); }
Diagramma di flusso (Flowchart) del costrutto if-else.

8. Operatori Relazionali e Logici

Gli operatori relazionali confrontano due valori: == (uguale), != (diverso), >, <, ecc.

Gli operatori Logici uniscono più condizioni:

  • AND (&&): Ritorna 1 solo se ENTRAMBE le condizioni sono vere.
  • OR (||): Ritorna 1 se ALMENO UNA condizione è vera.
  • NOT (!): Inverte il valore logico (es. != significa "diverso da").

Trucchi di Programmazione Booleana

Poiché un'espressione logica in C vale letteralmente 1 o 0, possiamo usare la matematica per sostituire alcuni costrutti if:

/* Anziché usare due if: */ /* if (type == 1) { a = 10; } */ /* if (type == 2) { a = 20; } */ /* Possiamo scrivere un'equazione algebrica diretta: */ a = (type == 1) * 10 + (type == 2) * 20;

Se type è 1, avremo: (1)*10 + (0)*20 = 10. Nessun salto condizionale richiesto dal processore, codice più veloce e compatto.
