Il Costrutto while e gli Operatori in C

1. Il costrutto while

Il costrutto while è un ciclo che ripete l'esecuzione di un blocco di codice finché una determinata condizione risulta vera.

Sintassi:

while (condizione) { // codice }
Alla fine della riga del while non va inserito alcun punto e virgola.

Nota importante: se la condizione di iterazione è falsa fin dall'inizio, il corpo del ciclo potrebbe non essere eseguito nemmeno una volta.

Fig 1. La condizione viene controllata prima di ogni esecuzione del corpo.
/* esempio illustrativo */ int i = 1; while (i <= 3) { printf("%d\n", i); i++; }

2. Casi particolari e condizioni complesse

Cicli infiniti: si crea un ciclo infinito usando una condizione sempre vera, ad esempio while (1). Può sembrare un errore, ma i cicli infiniti sono molto utili in certi contesti, come nella programmazione dei microcontrollori.

while (1) { // ciclo infinito: la condizione è sempre vera }

Condizioni multiple: si possono combinare più condizioni nel while con gli operatori logici, in modo che il ciclo continui solo se tutte o alcune delle condizioni sono soddisfatte.

OperatoreSignificatoIl ciclo continua se…
&&AND logicotutte le condizioni sono vere
||OR logicoalmeno una condizione è vera
while (a > 0 && b > 0) { // continua solo se ENTRAMBE le condizioni sono vere } while (a > 0 || b > 0) { // continua se ALMENO UNA condizione è vera }

3. Rappresentazione: flow chart e pseudo-codice

Nei diagrammi di flusso (flow chart) il costrutto si presenta con un blocco di decisione da cui parte il flusso che gestisce il controllo della condizione (Vero/Falso), mantenendo sempre un unico flusso in entrata e un unico flusso in uscita.

Fig 2. Flow chart del while: il ramo VERO esegue il corpo e torna alla condizione, il ramo FALSO esce dal ciclo.

Nello pseudo-codice si usa un linguaggio informale ma rigoroso, comprensibile all'essere umano, che descrive la logica del procedimento senza legarsi alla sintassi di uno specifico linguaggio di programmazione.

FINCHÉ (la condizione è vera) esegui il corpo del ciclo

4. Operatori di assegnamento abbreviati

In C è possibile abbreviare le operazioni aritmetiche combinandole con l'assegnazione:

OperatoreCosa fa
+=memorizza a + b in a
-=memorizza a − b in a
*=memorizza a × b in a
/=memorizza a / b in a
%=memorizza il resto a % b in a

5. Operatori di incremento e decremento

  • Postfissi (a++, a--): rendono disponibile il valore attuale della variabile e solo successivamente la incrementano o decrementano.
  • Prefissi (++a, --a): prima modificano (incrementano o decrementano) il valore della variabile e subito dopo lo rendono disponibile.
Fig 3. La differenza tra postfisso e prefisso sta nell’ordine delle due operazioni.
/* esempio illustrativo, con a = 5 */ b = a++; // b vale 5, poi a diventa 6 b = ++a; // a diventa 6, poi b vale 6
