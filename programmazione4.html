Il Costrutto for

1. I tipi di dato in C

Prima di introdurre il ciclo for è utile richiamare come il linguaggio C classifica i dati, perché la variabile di controllo del ciclo deve essere dichiarata con un tipo ben preciso. I tipi di dato in C si dividono in tre categorie principali:

Tipi primitivi. Comprendono i dati fondamentali come char (caratteri), int (interi), float e double (numeri con la virgola a singola o doppia precisione) e void (assenza di tipo). Nella dichiarazione, tutte le parole chiave devono essere scritte rigorosamente in minuscolo.

Tipi derivati. Includono elementi strutturati come gli Array, i Pointer (puntatori) e le Function (funzioni).

Tipi definiti dall'utente. Permettono di creare strutture personalizzate tramite enum (enumerazioni), Structure (strutture) e Union (unioni).

CategoriaTipi inclusiNote
Primitivichar, int, float, double, voidKeyword tutte in minuscolo
DerivatiArray, Pointer, FunctionCostruiti a partire dai primitivi
Definiti dall'utenteenum, Structure, UnionStrutture personalizzate

Esistono inoltre varianti basate sulla dimensione e sulla presenza o meno del segno (come short, long, unsigned int), e tipi booleani (_Bool o bool, includendo la libreria <stdbool.h>) che gestiscono i valori di verità true (1) e false (0).

È possibile inoltre assegnare un nuovo nome (un alias) a un tipo di dato esistente utilizzando l'istruzione typedef. Per la gestione di indici e dimensioni di oggetti in memoria, si utilizza spesso il tipo size_t, che garantisce l'utilizzo di un formato adeguato all'architettura hardware impiegata.

/* tipi primitivi */ int eta = 25; float altezza = 1.75f; double precisione = 3.141592653589793; char iniziale = 'A'; /* varianti dimensionali e segno */ short piccolo = -100; long grande = 1000000L; unsigned int senza_segno = 42; /* tipi booleani (con <stdbool.h>) */ #include <stdbool.h> bool attivo = true; // equivale a 1 bool spento = false; // equivale a 0 /* typedef: alias di un tipo esistente */ typedef unsigned int uint; uint numero = 42; /* size_t: indici e dimensioni in memoria */ size_t lunghezza = 1024;

2. Il costrutto for: struttura e sintassi

Il ciclo for è un'istruzione di iterazione che si utilizza tipicamente quando è noto a priori il numero di volte in cui il blocco di codice deve essere eseguito. La sua sintassi prevede tre elementi fondamentali racchiusi tra parentesi e separati da punto e virgola:

for (inizializzazione; condizione; istruzione_finale) { // corpo del ciclo }

1. Istruzione di inizializzazione: definisce e imposta la variabile di controllo (es. int i = 0).

2. Condizione: l'espressione che viene verificata prima di ogni iterazione; se è vera, il ciclo continua.

3. Istruzione finale: l'operazione eseguita alla fine di ogni giro, solitamente l'incremento o decremento della variabile (es. i++).

Il flusso logico è quindi: si esegue una sola volta l'inizializzazione, poi si valuta la condizione; se è vera si esegue il corpo, poi l'istruzione finale e si torna a valutare la condizione; se è falsa si esce dal ciclo.

/* esempio: stampa dei numeri da 0 a 9 */ for (int i = 0; i < 10; i++) { printf("%d\n", i); }

Nell'esempio: int i = 0 è l'inizializzazione, i < 10 è la condizione, i++ è l'istruzione finale. Il corpo viene eseguito per i = 0, 1, 2, …, 9, ossia 10 volte in totale.

3. Visibilità della variabile di controllo

La visibilità (scope) della variabile di controllo dipende da dove viene dichiarata:

  • Dichiarata direttamente all'interno delle parentesi del for: la sua validità resta confinata esclusivamente all'interno del corpo del loop. Fuori dal ciclo la variabile non esiste più.
  • Dichiarata all'esterno del ciclo: rimane accessibile anche dopo la fine del ciclo, conservando l'ultimo valore assunto.
/* Caso 1: variabile dichiarata DENTRO il for */ for (int i = 0; i < 10; i++) { printf("%d\n", i); } // i NON è più visibile qui: usarla causerebbe un errore /* Caso 2: variabile dichiarata FUORI dal for */ int j; for (j = 0; j < 10; j++) { printf("%d\n", j); } // j è ancora visibile e, dopo il ciclo, vale 10 printf("j = %d\n", j);

La prima forma è quella preferibile quando la variabile serve solo come contatore, perché riduce al minimo lo scope e rende il codice più leggibile. La seconda forma è utile quando il valore finale della variabile deve essere riutilizzato dopo il ciclo.

4. Flow chart e derivazione dal while

Dal punto di vista logico, il ciclo for non possiede un diagramma di flusso (flow chart) dedicato: deriva direttamente dalla struttura del ciclo while, inserendo l'istruzione preparatoria (l'inizializzazione) subito prima dell'inizio del controllo condizionale. In altre parole, il for è un while con l'inizializzazione "incorporata" prima del controllo e l'istruzione finale "incorporata" alla fine di ogni iterazione.

Il confronto con il while rende evidente la derivazione:

AspettoCiclo whileCiclo for
InizializzazioneIstruzione separata, prima del cicloIncorporata nell'header del for
ControlloPre-test (prima del corpo)Pre-test (prima del corpo)
Istruzione finaleScritta manualmente nel corpoIncorporata nell'header del for
Flow chartDedicatoDerivato dal while
Uso tipicoNumero di iterazioni non notoNumero di iterazioni noto a priori

In pratica, ogni for può essere riscritto come while spostando l'inizializzazione prima del ciclo e l'istruzione finale alla fine del corpo. Il for è quindi una forma compatta e leggibile del while, particolarmente comoda quando tutte e tre le parti del ciclo sono legate alla stessa variabile di controllo.
